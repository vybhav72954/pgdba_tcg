how to submit your card
01
Copy the markdown
Hit the green button above. The full .md file contents are copied to your clipboard.
02
Create the file
In your fork, inside the cards/ folder, create a new file named exactly your GitHub handle.
cards/your-handle.md
03
Commit & push
Add, commit, and push to your feature branch — not main.
git checkout -b card/your-handle
git add .
git commit -m "card: Add your-handle"
git push origin card/your-handle
04
Open the PR
Go to your fork on GitHub. Open a Pull Request to the class repo. In the description, write:
Fixes #YOUR-ISSUE-NUMBER
